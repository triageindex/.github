# Triage Index

**Behavioral Signatures for AI systems. Measured. Not judged.**

AI systems can be asked to protect privacy, follow instructions, tell the truth and care for people. Triage Index records what they do when those responsibilities conflict.

A Behavioral Signature is the complete, versioned record of an AI system's responses to a shared set of dilemmas, kept with the question and the conditions that produced each answer. Triage Index publishes the questions, conditions, responses, calculations and history. It does not tell you what to believe.
